# 🔴 Mars Chat

> Local office chat application — simple, fast, beautiful.

## Features

- 💬 Personal Chat (DM)
- 👥 Group Chat
- 📎 File & Image Upload (max 10MB)
- 🟢 Online Status
- ⌨️ Typing Indicator
- 🔍 Search Conversations
- 📱 Responsive Design (Mobile + Desktop)
- ⚡ Real-time via WebSocket

## Tech Stack

| Component | Technology |
|-----------|------------|
| Backend | Python FastAPI |
| Real-time | WebSocket |
| Database | SQLite |
| Frontend | HTML, TailwindCSS, Alpine.js |
| Server | Uvicorn |

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run
python app.py

# Open browser
http://localhost:8080
```

## Default Port

`8080` — accessible from all devices on the same network via `http://<server-ip>:8080`
